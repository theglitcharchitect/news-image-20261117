One image that sums up Tuesday 17 November 2026's world news, from verified wire research: a briefing poster of the day's seven most consequential developments (the Crimea Bridge strikes and Kyiv hit, the contested Iranian drone attack on the US base in Bahrain, Trump's Asia tour and Asia diplomacy, the global AI sell-off and Nvidia's beat, the US, Mexico and Bolivia losing measles elimination status, Israel electing a Knesset speaker with no evidence of vote-buying, and COP31 deadlock alongside the Ebola and Sudan tolls), plus a market snapshot, a timeline, and regional gap-pass stories from Bangladesh, Iraq, Mozambique, Czechia and Japan, each labelled Confirmed, Developing or Contested. `main.py` (Python 3.13, standard library only, no network) copies the poster's JPEG bytes, held in the repository as `entry.jpg` (1024 by 683 pixels, 313,525 bytes), to `/output/entry.png`, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png, the same bytes on every run
```
